# Skill 05: Premium Frontend UI Layout

## Core Directives

- _Anti-Boileplate Aesthetic:_ Actively move away from identical, generic layouts (e.g., standard soft grey SaaS card matrices with indigo gradient outlines). Embrace high-intent asymmetric structures, elegant whitespace rules, unique typographic scale ratios, and crisp editorial typography configurations.
- _Absolute Contrast Compliance:_ Maintain a strict minimum WCAG contrast standard of 4.5:1 for structural read strings and 3:1 for decorative display headlines. Never pair low-value grey text fields against low-value backgrounds.
- _Device-Agnostic Viewport Scaling:_ Layout fluid systems using explicit design breakpoint logic. Elements must scale smoothly across display types, remaining functional down to a strict 360px wide native mobile canvas without breaking component grids or clipping essential data.
